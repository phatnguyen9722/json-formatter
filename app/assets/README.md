# Assets Directory

This directory contains application assets including:

- `icon.png` - Application window icon (256x256 PNG recommended)
- `icon.ico` - Windows icon fallback (optional)

## Adding Your Logo

1. Place your logo image as `icon.png` in this directory
2. Recommended size: 256x256 pixels
3. Format: PNG with transparency support
4. For Windows compatibility, you can also add `icon.ico`

The application will automatically load and display the icon when it starts.
