
# JSON Formatter 

### Presiquites
- Install `uv`
- Install through `pip`
```
pip install uv
```

### Install libraries/packages
```
uv sync
```


### Run this application
```
uv run -m app.main
```

### To build binary files:
```
uv run build_binary.py
```
- Binary files are stored in `/dist` folder. </br>
